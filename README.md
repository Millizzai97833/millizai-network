# Millizai Network — GitHub Pages Starter
Created by Shahab Millizai.

## Included
- Mobile-friendly crypto gaming landing page
- Bird Launcher (original slingshot-style mini-game), Neon Snake, Fruit Slice
- Local-device best score and sample leaderboard
- DOGE and SOL public receiving address fields
- Planned minimum payout thresholds: **1 DOGE** and **0.002 SOL**
- Privacy, competition rules and contact pages

## Important: prototype only
This is a static frontend. It does not provide real accounts, a global leaderboard, server-side anti-cheat, verified competition scoring, blockchain wallet integration, withdrawal processing, or crypto payments. Scores and wallet addresses are stored only in the current browser. The leaderboard contains sample entries. No crypto is earned or paid. Monthly prizes must not be advertised as active until you have published rules, eligibility, dates and a fully funded prize pool. Never collect seed phrases or private keys.

## Publish on GitHub Pages
1. Create a public repository named `millizai-network`.
2. Extract this ZIP and upload the contents directly to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
5. Your site will appear at `https://YOUR-USERNAME.github.io/millizai-network/`.

## AdSense
After publishing, add your own AdSense verification snippet inside the `<head>` of `index.html`, exactly as Google supplies it. Apply for review; approval is not guaranteed. Keep ads away from game controls. Never reward ad views or clicks with crypto or points. Review current Google publisher policies before applying.

## Before real launch
Add a secure backend, user authentication, server-side score validation, abuse prevention, payout processing and accurate legal/privacy disclosures. Check local legal requirements before operating a crypto prize or payment program.
